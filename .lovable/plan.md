# تنظيف المشروع وتغيير الهوية إلى elgiza

## الهدف

تقليل الكود القديم وغير المستخدم مع الحفاظ على الخدمات الحالية، ثم استبدال الاسم الظاهر Megsy بـ **elgiza** واستخدام الشعار المرفق كما هو. لا إعادة كتابة شاملة ولا تغيير للمزودين أو النماذج أو حسابات المستخدمين.

## نتائج الفحص الأساسية

- 98 اختبارًا ناجحًا في 24 ملفًا؛ هذه نقطة المقارنة لكل مرحلة.
- نحو 1030 عنصرًا في كتالوج التطبيقات؛ هذه **تكاملات خارجية وليست ألف مزود ذكاء اصطناعي**. الكتالوج المولد وحده 10012 سطرًا.
- يوجد 164 نمط مسار، كثير منها تحويلات توافقية؛ لا يجوز اعتبار كل مسار صفحة مستقلة أو حذفه دون تتبع استخدامه.
- CSS الأساسي 8103 أسطر مع تكرار يحتاج فصلًا ومقارنة؛ لا حذف نصف الملف عشوائيًا.
- الاسم موزع بين نصوص الواجهة ومفاتيح التخزين وأسماء أحداث وروابط وعقود خدمات؛ الاستبدال الشامل سيضر التوافق.
- الشعار المرفق JPEG بحجم 256×256، برتقالي على أسود؛ يستخدم كما هو دون إعادة تصميم، وتبقى الواجهة الأساسية أبيض وأسود.

## مراحل التنفيذ بعد الموافقة

### 1. حذف الأدلة المؤكدة على الكود غير المستخدم

حذف الاستيرادات والتصديرات الكسولة غير المستهلكة، ثم صفحات ومكونات يتأكد عدم الوصول إليها من أي مسار أو استيراد ديناميكي أو ملف إعداد. تنظيف كل مجموعة صغيرة وحدها، مع الاحتفاظ بتحويلات الروابط القديمة والوظائف المستخدمة خارج المتصفح.

**التحقق:** الاختبارات الحالية، البناء التلقائي، فتح الترحيب وتسجيل الدخول والأسعار والتطبيقات، وفحص التحويلات المتأثرة؛ لا تجاوز للتحقق بالبريد.

### 2. توحيد النسخ المتكررة تدريجيًا

دمج الأدوات والمساعدات والأنماط المتكررة التي ثبت تطابق سلوكها. إزالة النسخ المهجورة بعد نقل مستهلكيها. توحيد التنقل تدريجيًا على TanStack الموجود بدل توسيع نظامي تنقل متوازيين، مع تثبيت الروابط والمحتوى وحماية الصفحات.

**التحقق:** اختبارات المسارات والروابط القديمة، مقارنة الصور والسلوك لكل منطقة، وعدم تغيير بيانات أو واجهة الخدمات.

### 3. فصل مزودي الذكاء الاصطناعي عن كتالوج التطبيقات

تثبيت خريطة المسارات الحالية لكل خدمة: الدردشة، الصور، الفيديو، البحث، الصوت والوكلاء. حذف محولات مزودين فقط إن ثبت عدم استدعائها وعدم اعتماد وظيفة منشورة أو fallback عليها. التعامل مع التكاملات كجزء مستقل، وتحميل كتالوجها عند الحاجة بدل تحميل وعرض الألف عنصر مرة واحدة، دون إلغاء تكامل متاح أو تغيير اختيارات المستخدم.

**التحقق:** اختبارات مسار كل خدمة والبحث وفتح تفاصيل التطبيقات؛ الاختبارات الحية المدفوعة أو داخل الحساب تظل غير مؤكدة دون وصول مشروع مناسب.

### 4. تقليل CSS والاعتماديات

إزالة كتل مكررة بعد مقارنة الترتيب والـcascade، وفصل أنماط الصفحات إلى تحميلها المناسب. حذف الحزم فقط بعد اختفاء جميع مستخدميها من التطبيق والخادم والاختبارات والإعدادات. لا ترقيات رئيسية أو تغيير مزودين ضمن تنظيف الكود.

**التحقق:** البناء والاختبارات، صور الهاتف وسطح المكتب والفاتح والداكن، والقياس قبل/بعد في نفس البيئة؛ لا نسب سرعة أو توفير بلا قياس.

### 5. تغيير الاسم والشعار إلى elgiza

إنشاء تعريف واحد للاسم والشعار وإعادة استخدامه في مكونات الهوية. تحديث النصوص الظاهرة بالإنجليزية والعربية، تسجيل الدخول والترحيب والشريط الجانبي والأسعار والمشاركة وتصدير الملفات وبيانات الصفحات والتطبيق المثبت. استيراد الصورة عبر نظام الأصول، وتجهيز أيقونة موقع مناسبة من نفس الصورة عند الحاجة دون تغيير الرسم.

يبقى البرتقالي لون الشعار نفسه، وليس تحويل الواجهة كلها إلى برتقالي. لا نغيّر الدومينات أو بريد الدعم أو روابط الدفع أو أسماء الجداول أو مفاتيح `megsy_*` أو بروتوكول `megsy.send` أو معرفات المزودين لمجرد تغيير العلامة. اسم المشروع داخل لوحة Lovable يُراجع منفصلًا عن الاسم الظاهر؛ لا نفترض أن تغيير النصوص يعيد تسميته في اللوحة.

**التحقق:** مراجعة جميع المواضع الظاهرة للاسم القديم، تحميل الشعار وأيقونة الموقع على الفاتح والداكن والهاتف، وتأكيد بقاء تفضيلات المستخدم وبياناته وروابطه القديمة.

## ما يبقى خارج الحذف التلقائي

- ترحيلات قاعدة البيانات وسجلها، ملفات الأسرار، الوظائف المجدولة/webhooks المنشورة، والبيانات الفعلية.
- مفاتيح أو معرفات أو عناوين تعتمد عليها جلسات أو خدمات خارجية.
- أي مسار لا يمكن التحقق من عدم استخدامه؛ يُسجل مع سبب عدم حذفه بدل التخمين.
- إصلاحات الأمان الخطيرة المذكورة في تقرير الفحص السابق: لها معالجة مستقلة، والتنظيف وحده لا يجعل التطبيق آمنًا.

## التسليم

قائمة بالملفات والحزم المحذوفة وأسبابها، ما تم دمجه، خريطة الخدمات المتبقية، نتيجة الاختبارات، مقارنة أحجام الملفات، والاسم والشعار الجديدان بعد التحقق. كل مرحلة تترك التطبيق يعمل ويمكن مراجعتها قبل التالية.
